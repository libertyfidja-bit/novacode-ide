# NovaCode Studio — Multi-Language Cloud IDE & NovaAI

- **Zero Server Cost**: Runs Python 3.12 via WebAssembly (Pyodide) and JavaScript natively in the user's browser.
- **NovaAI Assistant (Gemini Free Tier)**: Prompt Gemini AI to write, explain, and debug code with 1-click Apply to Editor.
- **Line-by-Line Debugger**: Click any line number to set red breakpoints and inspect live variables.
- **12+ On-Demand Extensions**: Users install only the language packs and AI tools they need.
